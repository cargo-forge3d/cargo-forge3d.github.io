About the project

CargoForge is built for interview-visible engineering depth.

This website presents a port-oriented 3D reconstruction system that connects algorithmic adaptation, low-VRAM inference, multi-GPU serving, and digital twin asset production. The goal is to make the project understandable to engineers and interviewers without hiding the system details behind a demo.

Project context

The work is motivated by breakbulk cargo terminals, where timber crates, steel structures, pipe bundles, and irregular machinery components need to be reconstructed as reusable 3D assets. The system focuses on non-contact image capture, fast mesh generation, GLB/PBR export, and digital twin ingestion.

Engineering scope

CargoForge is not a single notebook pipeline. It includes Windows adaptation for Hunyuan3D-2.1, local model cache handling, HiCache++ acceleration, low-VRAM texture experiments, FastAPI serving, Redis queues, PostgreSQL job state, dual-GPU workers, failure cleanup, and pressure-test metrics.

Research scope

The domain adaptation part converts teacher-generated GLB assets into watertight meshes, SDF samples, and multi-view render conditions. Rank-16 LoRA is used to improve open-source Hunyuan3D-2.1 on cargo-specific geometry while keeping the model adaptation lightweight.

Author

Developed by Zezhong Li, Tianjin University. The system is part of a broader effort on industrial AI, generative 3D reconstruction, and port digital twin asset generation.
